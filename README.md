# 🛍️ Verve - Flutter Fashion App

A modern fashion shopping mobile application built with **Flutter & Dart**.

## 📱 About The Project

**Verve** is a fashion e-commerce mobile application designed to provide users with a simple and modern shopping experience.

The app includes different fashion categories, products, best sellers, hot drops, winter sales, inspirational sections, favorites, cart, and profile screens.

## ✨ Features

* 🏠 Home Page
* 👕 Fashion Categories
* 🔥 Hot Drops
* ⭐ Best Sellers
* ❄️ Winter Sale
* 💡 Inspirational Section
* 🧥 Jackets
* 🏕️ Outdoors
* ❤️ Favorites
* 🛒 Shopping Cart
* 👤 Profile
* 🔎 Search
* 📱 Bottom Navigation

## 🛠️ Technologies

* Flutter
* Dart
* Material Design
* Android Studio / VS Code

## 🎨 UI Design

The application focuses on a clean, modern, and minimal fashion-shopping interface using a black and white visual style.

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/esr470/verve-flutter-app.git
```

### 2. Open the project

```bash
cd verve-flutter-app
```

### 3. Install dependencies

```bash
flutter pub get
```

### 4. Run the application

```bash
flutter run
```
